==============================================================================
5. QUERY PROCESSING COST
==============================================================================
  Accumulators only touch documents that hold a query term, so the
  rest of the collection is never scored. The smoothed language
  model is the exception: every document gets a non-zero score, so
  all 1,460 have to be ranked however short the query is.

  query      terms  TF-IDF/BM25   of all   JM LM
  Q3             5          890      61%    1460
  Q18           15          726      50%    1460
  Q35            7          800      55%    1460
  Q77           67         1304      89%    1460

  Q77 is a whole abstract used as a query, so it reaches almost
  every document; the short questions reach far fewer.

==============================================================================
7. WHY THESE PARAMETERS (MODEL SELECTION)
==============================================================================
  BM25: b controls the length penalty. CISI abstracts are short and
  fairly even in length, so the default 0.75 is not critical.

  setting                                P@10   R-prec
  BM25, b = 0.0                         0.270    0.193
  BM25, b = 0.5                         0.304    0.206
  BM25, b = 0.75                        0.316    0.209
  BM25, b = 1.0                         0.300    0.213

  Language model: lambda is the weight on the collection model.
  Zhai and Lafferty (2004) report that long queries need heavy
  smoothing. CISI queries are long and the sweep agrees: P@10 is
  flat from 0.5 to 0.7, and R-precision keeps climbing past it.
  JM LM, lambda = 0.1                   0.342    0.221
  JM LM, lambda = 0.3                   0.358    0.231
  JM LM, lambda = 0.5                   0.370    0.236
  JM LM, lambda = 0.7                   0.362    0.240
  JM LM, lambda = 0.9                   0.355    0.249
